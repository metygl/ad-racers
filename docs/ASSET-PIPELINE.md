# Asset pipeline

## There are no asset files

Search the repository for a `.png`, `.jpg`, `.glb`, `.gltf`, `.mp3`, `.ogg`,
`.wav` or `.ttf` and you will not find one. Every texture, mesh, sound and font
in AD Racers is either generated by code at load time or is a system font.

```
$ find . -path ./node_modules -prune -o \
    -regex '.*\.\(png\|jpg\|jpeg\|gif\|webp\|glb\|gltf\|fbx\|obj\|mp3\|ogg\|wav\|ttf\|woff2?\)$' -print
(nothing)
```

`scripts/check-provenance.mjs` enforces this in CI.

## Why

The brief asked whether Blender MCP, a scripted glTF pipeline or image-to-3D
tooling would materially improve quality. Each was evaluated and rejected, for
reasons that are specific rather than reflexive:

**Blender.** Not on `PATH` in this environment, and the brief forbids
installing system-wide software or changing global configuration. Beyond that,
a Blender step would make CI depend on a large binary that GitHub's runners do
not ship — for assets that, at this art direction, are stacked primitives. A
build that cannot run on a clean checkout is not a pipeline, it is a liability.

**Image-to-3D services.** Rejected on provenance grounds. An asset whose
training data and licence cannot be stated is not something this repository can
honestly ship, and "we generated it, so it is ours" is not a licence.

**Downloaded assets (Poly Haven, Sketchfab, etc.).** Would work and are
properly licensed, but they mean binary files, attribution obligations and a
download budget — for a low-poly stylised look that primitives already produce.

## What we got instead

| Property | Result |
| --- | --- |
| Binary assets | 0 |
| Total download | **178 kB gzipped** (45 kB game + 133 kB three.js) |
| Provenance | Every pixel and sample traceable to a `.ts` file |
| Offline | A race starts with the network unplugged |
| Reproducible | Seeded; byte-identical on every machine and run |
| Licence obligations | One (three.js, MIT) |

The trade is real and worth stating: this art direction is *chosen*, not
merely achievable. Photoreal surfacing, sculpted characters or recorded audio
would need a different pipeline. Within a stylised low-poly brief, procedural
generation is not a compromise — it is smaller, faster, and completely
auditable.

## Textures — `src/render/textures/procedural.ts`

Drawn into a `<canvas>` at load, uploaded once as a `CanvasTexture`.

- **Value noise on a torus**, so every texture tiles seamlessly. Several
  octaves are summed into an fBm field.
- **Road** (`roadTexture`): mottled tarmac, darkened wheel tracks at a third
  and two thirds of the width, and a dashed centre line baked into the same
  image — so the whole road stays a single draw call. The line is faded and
  broken up by a seeded RNG so it reads as three centuries old.
- **Surfaces** (`surfaceTexture`): base colour modulated by fBm brightness,
  with optional flecks. Used for the shoulders, terrain and rock.
- **Particles** (`particleTexture`): one soft radial falloff serves dust,
  sparks, embers and impacts. Colour comes from the instance, never the
  texture.

Every generator is seeded from the track definition, so the same course looks
identical everywhere. Textures are cached by key and disposed on teardown and
on WebGL context loss.

## Geometry

Built from `three` primitives and merged where it helps.

- **Track** (`scene/TrackMesh.ts`): a ribbon extruded along the same
  `PathSample` array the physics projects against — so the road you see and the
  road you drive on cannot disagree. Road, shoulder and barrier are three
  merged buffer geometries per path.
- **Scenery** (`scene/Scenery.ts`): each species is a handful of primitives
  merged into one prototype geometry, then drawn as a single `InstancedMesh`
  however many instances exist. Scatter is seeded and rejects any placement
  within 2.5 m of a drivable corridor, including shortcuts.
- **Terrain** (`scene/Terrain.ts`): a heightfield with vertex colours. The
  interesting part is the blend — inside the corridor the terrain is pinned to
  the road's own elevation, then eases out into free noise over 26 m. Without
  it the road either floats or is buried wherever the course climbs.
- **Skiffs** (`scene/VehicleModel.ts`): about twenty primitives. Silhouette is
  the whole design goal — at 45 m/s with six on screen the player has to tell
  them apart in a glance, so each is a long low hull in the crew colour, a swept
  fin, and an offset pod on a visible spar.
- **Sky** (`scene/SkyDome.ts`): an inverted sphere with a small custom shader —
  vertical gradient, sun disc with bloom, and a drifting procedural cloud band.
  A shader rather than a gradient texture, so the horizon never bands.

## Audio — `src/audio/synth.ts`

Rendered into `AudioBuffer`s at startup, after the first user gesture.

| Sound | Method |
| --- | --- |
| Engine | One cycle of an asymmetric saw plus growl and grit, looped; playback rate follows RPM |
| Impacts, scrapes | Noise through a state-variable lowpass with a resonance term |
| Countdown, laps, UI | Additive sine harmonics with an exponential envelope |
| Surge, drift release | Frequency sweeps with a noise component |
| Ambience | Five detuned partials over a root, each completing a whole number of cycles so the loop is click-free |

Noise comes from a hash function, not `Math.random`, so buffers are identical
every run. Every generator ends with `normalise()`.

> Web Audio hard-clips outside [-1, 1]. `tone` summed harmonics to 1.47 and
> `noiseBurst`'s resonant filter overshot to 1.03 — both audibly distorted, and
> both invisible until `tests/unit/audio.test.ts` asserted it. Normalising
> afterwards makes the peak a property of the API rather than something a
> tuning change can quietly break.

## Fonts and icons

System font stack only (`ui-sans-serif, system-ui, …`). No web font: a download
that can fail is a download this game does not need. The favicon is an inline
SVG data URI in `index.html`.

## Adding an asset

If a future asset genuinely cannot be generated:

1. Prefer extending the procedural generators.
2. If a binary is unavoidable, record its source, author, licence and URL in
   [PROVENANCE.md](./PROVENANCE.md) **in the same commit**.
3. Add its extension to the allowlist in `scripts/check-provenance.mjs`, with a
   comment saying why.
4. Check it against the download budget in [PERFORMANCE.md](./PERFORMANCE.md).

The provenance check failing is the intended behaviour, not an obstacle: it
means an undocumented binary would otherwise have shipped.
